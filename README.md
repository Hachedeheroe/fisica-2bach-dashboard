# Dashboard SaaS para Física 2º Bachillerato

Aplicación SaaS para ayudar a estudiantes de 2º de Bachillerato en su aprendizaje y seguimiento de la asignatura de Física.

## Características

- Dashboard con métricas de rendimiento
- Gestión y revisión de exámenes
- Asistente IA especializado en física
- Análisis personalizado de áreas de mejora

## Tecnologías

- React + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- TanStack Query para gestión de datos
- Zustand para estado global
- Clerk para autenticación
- Anthropic Claude API para asistencia IA

## Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Ejecutar tests
npm test

# Construir para producción
npm run build
```
